# EvidSynthTB: Bayesian Multi-Parameter Evidence Synthesis for TB Epidemiology

Bayesian Multi-Parameter Evidence Synthesis (MPES) linking latent
tuberculosis infection (LTBI) diagnostic survey data with active TB
progression survival data using mixture cure models, imperfect
diagnostic test models, and modular/cut inference in Stan.
